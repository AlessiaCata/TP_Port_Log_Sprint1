# Port Log - Sprint 1

## Objetivo

Aplicar conocimientos de versionado, organización y análisis exploratorio
de datos con pandas sobre un dataset real de operaciones portuarias.

## Introducción y contexto

El Puerto Fluvial de Rosario es uno de los complejos portuarios más importantes
de América del Sur y constituye un punto clave para la exportación de granos
y derivados de Argentina.

El sistema de registro de movimientos portuarios fue migrado desde un sistema
antiguo que acumuló inconsistencias en fechas, matrículas de buques y valores
numéricos.

El objetivo de este sprint es analizar y depurar los datos para poder
incorporarlos correctamente al nuevo sistema.
